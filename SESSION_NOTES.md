## 2026-07-17 — Этап 2: первый vertical slice

Результат: полный локальный цикл `профиль → контрагент → заказ → счёт → подтверждение → PDF → audit log`.

- `lib/domain/repository.ts` — интерфейсы репозиториев.
- `lib/storage/local-repositories.ts` — локальные реализации через `node:fs`.
- application services для профиля, контрагентов, заказов и счетов.
- API профиля, контрагентов, заказов, счетов, PDF и audit events.
- UI списка, создания и просмотра заказов.
- UI проверки и подтверждения счетов.
- UI истории решений.
- PDF A4 через `pdf-lib`.
- append-only audit log и идемпотентность.

# DATA_SOURCES

## Исходный набор

Источник: архив «ИП Гранд Мебель.zip», переданный владельцем 16.07.2026.

Предварительно обнаружено 210 деловых файлов после исключения технических зависимостей:

- 110 XLSX;
- 39 PDF;
- 24 DOCX;
- XML ЭСФ;
- изображения печати и подписи;
- другие рабочие форматы.

## Классы источников

- профиль ИП и уведомления;
- контрагенты и реквизиты;
- договоры и приложения;
- счета 2025–2026;
- накладные З-2;
- акты Р-1;
- банковские выписки и реестры поступлений;
- ЭСФ PDF/XML;
- графические реквизиты.

## Правила

- `data/raw/` — неизменяемые оригиналы, не коммитятся.
- `data/working/` — временные результаты извлечения, не коммитятся.
- `data/processed/` — нормализованные закрытые данные, не коммитятся.
- `data/demo/` — только синтетические/обезличенные примеры, допускаются в Git после проверки.
- Каждый импорт сохраняет источник, хеш, время и версию парсера.
- Конфликтующие сведения не перезаписываются автоматически.

## Происхождение шаблонов

Проверка метаданных не обнаружила надёжного единого маркера MyBuh. Значительная часть Excel редактировалась вручную или создана сторонними шаблонами. Поэтому импорт не должен определять источник только по внешнему виду файла. Источник классифицируется по содержанию, метаданным и подтверждённой пользователем истории.

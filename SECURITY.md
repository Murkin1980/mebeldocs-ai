# SECURITY

## Классификация

Реальные документы содержат ИИН/БИН, банковские реквизиты, адреса, подписи, печати, договоры и финансовые суммы.

## Обязательные меры

- Шифрование файлов и резервных копий.
- TLS для передачи.
- 2FA для владельца и бухгалтера.
- Изоляция данных компаний.
- Роли с минимальными правами.
- Закрытый доступ к печати и подписи.
- Неизменяемый аудит скачивания, генерации, подписания и отправки.
- Секреты только через защищённое окружение.
- Маскирование персональных данных в логах и песочнице.
- Запрет загрузки реальных документов во внешние AI-сервисы без отдельного решения и настройки.
- Карантин архивов, лимиты распаковки и защита от zip-slip/zip-bomb.
- Запрет исполнения файлов из архива.
- Антивирусная/сигнатурная проверка до обработки.
- Политика хранения и удаления загруженного архива.
- Изоляция поискового индекса базы знаний по компании.
- Защита от prompt injection внутри загруженных документов: содержимое документа считается данными, а не инструкцией.

## Git

В Git запрещены `data/raw`, `data/processed`, выгрузки, подписи, печати, ЭЦП, банковские документы, `.env` и логи с реквизитами.

# ARCHITECTURE

## Принцип

Модульный монолит для пилота с готовностью к мультитенантности. ИИ извлекает намерение; правила, суммы, нумерация и сроки выполняются детерминированно.

## Контуры

1. Web/PWA и Telegram-ввод.
2. API приложения.
3. Компании, пользователи и роли.
4. Контрагенты, номенклатура, заказы и платежи.
5. Движок документов и шаблонов.
6. Движок обязательств и правил.
7. AI-оркестратор со структурированным результатом.
8. PostgreSQL, объектное хранилище, очередь задач.
9. Audit log без возможности тихого изменения истории.
10. Conversation orchestrator и управляемые сценарии помощника.
11. Archive intake/quarantine pipeline.
12. База знаний компании с поиском и ссылками на источники.

## Предварительный стек

- Frontend: Next.js/TypeScript.
- Backend: FastAPI/Python.
- База: PostgreSQL.
- Очередь/кэш: Redis после MVP.
- Документы: DOCX/XLSX-шаблоны → PDF.
- Файлы: S3-совместимое зашифрованное хранилище.
- Развёртывание пилота: Docker Compose.

## Ключевая модель

`company → counterparty → contract → order → invoice → payment → fulfillment → closing_document → esf_obligation`

## Агрегат реализации

`sale` является центральным агрегатом:

- может ссылаться на счёт и наследовать его строки;
- делит строки на `goods` и `services`;
- создаёт З-2 и/или Р-1;
- после проведения создаёт складские движения и ЭСФ-обязательство;
- отменяется реверсивным событием, а не удалением истории.

Состояния: `draft`, `ready_for_approval`, `approved`, `posted`, `partially_closed`, `closed`, `reversed`.

Платёж хранится независимо и связывается со счётом/реализацией через подтверждённое сопоставление.

## Среды

- `pilot`: реальные данные одной компании, без автоматической внешней отправки.
- `sandbox-private`: маскированная копия для проверки сценариев.
- `demo-public`: синтетические данные, жёсткая блокировка внешних действий.
- `production`: будущая SaaS-среда.

## Контур помощника

`conversation → workflow state → tool proposal → user confirmation → domain command → audit event`.

Помощник не пишет напрямую в таблицы. Он вызывает доменные команды с проверками прав и идемпотентностью.

## Контур архива

`upload → quarantine → security scan → manifest/hash → extraction candidates → review → approved import`.

Оригиналы неизменяемы. Повторный архив распознаётся по хешу. Индекс знаний хранит ссылки на файл и конкретный фрагмент; ответ без источника помечается как вывод/предположение.

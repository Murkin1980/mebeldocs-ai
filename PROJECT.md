# MebelDocs AI — паспорт проекта

Каноническое имя: **MebelDocs AI**.

Назначение: AI-сервис документооборота и бухгалтерского сопровождения мебельных ИП Казахстана.

Пилот: ИП «Гранд Мебель».

Главный вход в документацию: `README.md`.

Текущий этап: нормализация исходных данных и восстановление цепочек `счёт → реализация → З-2/Р-1 → ЭСФ → платёж`.

Проект ведётся независимо от истории чата:

- решения — `DECISIONS.md`;
- план — `ROADMAP.md`;
- выполненные действия — `SESSION_NOTES.md`;
- правила AI-кодеров — `AGENTS.md`;
- исходные документы — `data/raw/` (вне Git);
- повторяемые инструменты — `tools/`.

# MebelDocs AI — паспорт проекта

Каноническое имя: **MebelDocs AI**.

Назначение: AI-сервис документооборота и бухгалтерского сопровождения мебельных ИП Казахстана.

Пилот: ИП «Гранд Мебель».

Главный вход в документацию: `README.md`.

## Текущая стадия

Локальный функциональный MVP завершил первый вертикальный сценарий:

`профиль компании → контрагент → заказ → счёт → подтверждение → PDF → audit log`

Дополнительно реализованы:

- учёт и сопоставление платежей;
- расчёт остатка по счёту;
- сторнирование платежа с причиной;
- импорт и проверка ЭСФ XML;
- серверный auth guard для операций записи;
- append-only события и идемпотентность;
- 199 автоматических тестов по состоянию последнего функционального этапа.

Текущий приоритет: **стабилизация существующего контура и подготовка закрытого Cloudflare preview без реальных данных**.

До закрытого пилота необходимо:

1. закрыть дефекты PDF и проверить кириллицу;
2. завершить UI платежей, ЭСФ, профиля и контрагентов;
3. добавить GitHub Actions CI;
4. убрать runtime-зависимость от `node:fs`;
5. развернуть preview через Cloudflare Workers/OpenNext;
6. подключить D1/PostgreSQL и private R2;
7. провести security/privacy review и тест восстановления.

Подробный порядок: `NEXT_STAGES_PLAN.md`.

## Границы

Не считать готовыми до отдельной проверки:

- полноценную пользовательскую аутентификацию;
- мультитенантность;
- автоматическую отправку документов;
- ЭЦП и прямую отправку в ИС ЭСФ;
- AI-приёмщик в теневом режиме;
- SketchUp MCP.

## Источники истины проекта

Проект ведётся независимо от истории чата:

- текущий статус — `README.md` и этот файл;
- план — `ROADMAP.md` и `NEXT_STAGES_PLAN.md`;
- решения — `DECISIONS.md`;
- выполненные действия — `SESSION_NOTES.md`;
- правила AI-кодеров — `AGENTS.md`;
- исходные документы — `data/raw/` (вне Git);
- рабочие производные данные — `data/working/` (вне Git);
- повторяемые инструменты — `tools/`.

# AI_INFRA_DECISION

## ИИ разрешён для

- распознавания голосовой/текстовой команды;
- извлечения полей из документов;
- поиска вероятного контрагента и позиции;
- классификации товара/услуги как предложения;
- объяснения ошибок и расхождений;
- проверки полноты комплекта.
- ведения пошагового onboarding-сценария;
- предложения структуры базы знаний;
- объяснения ошибок и вариантов исправления;
- поиска по архиву с обязательной ссылкой на источник.

## ИИ запрещён как единственный механизм для

- арифметики и итогов;
- нумерации;
- определения налоговой ставки;
- окончательного решения об обязательности ЭСФ;
- расчёта срока без подтверждённого события;
- подписания и отправки;
- изменения проведённого документа.

## Экономика

Кэшировать справочники, использовать малые модели для извлечения, не вызывать ИИ при повторной генерации шаблона. Клиенту показывать лимит AI-операций, а внутри учитывать токены, OCR, хранение и уведомления.

## Контекст компании

В модель передаётся минимально необходимый набор фрагментов. Полный архив не помещается в один запрос. Структурированные данные запрашиваются через инструменты, документы — через поиск с контролем прав и источников. Подтверждённые решения пользователя имеют приоритет над новым предположением модели.

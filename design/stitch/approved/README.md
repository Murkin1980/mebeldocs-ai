# Approved designs

Здесь хранятся только утверждённые варианты. Для каждого варианта нужны:

1. desktop PNG;
2. mobile PNG;
3. `DECISION.md` — что выбрано и почему;
4. ссылка на исходный Stitch-проект;
5. список отличий от текущего `apps/web`.

Наличие файла здесь ещё не означает, что дизайн реализован в коде.

# Raw Stitch code export

Сюда помещается код, экспортированный Stitch, без запуска и без автоматического объединения с `apps/web`.

Сохраните исходную структуру экспорта. Не добавляйте `node_modules`, `.env`, API-ключи и build-артефакты. Если Stitch выдаёт один HTML-файл, сохраните его как `archive-review-vNN.html`; CSS и изображения положите рядом в папку той же версии.

# Google Stitch workspace

Эта папка хранит дизайн-эксперименты MebelDocs AI отдельно от рабочего приложения `apps/web`.

## Структура

```text
design/stitch/
├── source/       ссылки, промпты и экспортированный Stitch DESIGN.md
├── screens/      PNG/WebP экранов desktop и mobile
├── code-export/  сырой HTML/CSS/React, выгруженный из Stitch
└── approved/     только выбранные и утверждённые варианты
```

## Главное правило

Экспорт Stitch никогда не копируется напрямую в `apps/web`. Сначала он сохраняется в `code-export`, сравнивается с действующим интерфейсом, проверяется на доступность, адаптивность и безопасность. Затем нужные решения вручную переносятся в приложение отдельным коммитом.

Все материалы в этой папке должны содержать только вымышленные данные. Реальные БИН/ИИН, IBAN, счета, печать, подпись и документы ИП запрещены.

## Имена файлов

Используйте латиницу и версию:

- `archive-review-desktop-v01.png`
- `archive-review-mobile-v01.png`
- `archive-review-states-v01.png`
- `DESIGN.stitch.v01.md`
- `archive-review-v01.html`
- `archive-review-v01.css`

После выбора варианта скопируйте изображения в `approved/` и добавьте рядом `DECISION.md` с причиной выбора и ссылкой на Stitch-проект.

## Что коммитить в GitHub

Коммитим: промпты, `DESIGN.md`, PNG/WebP, SVG-иконки, HTML/CSS/React-экспорт и решения. Не коммитим: реальные документы, секреты, огромные видео, временные ZIP и автоматически сгенерированные зависимости.

Рекомендуемый предел одного изображения — 5 МБ. Для крупных исходников лучше сохранить отдельную ссылку в `source/STITCH_PROJECT.md`.

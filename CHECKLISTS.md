# CHECKLISTS

## Приём исходных данных

- [x] Оригиналы не изменяются.
- [x] Для каждого файла рассчитан хеш.
- [x] Извлечены имя, тип, дата и размер.
- [x] Технические, временные и дублирующиеся файлы отмечены.
- [ ] PDF/сканы с низким качеством отправлены на OCR-проверку.
- [x] Персональные данные не попали в логи и Git.
- [ ] Архив помещён в карантин до обработки.
- [ ] Проверены zip-slip, zip-bomb, размер распаковки и вложенность.
- [ ] Исполняемые файлы заблокированы.
- [x] Повторная загрузка определена по хешу.
- [ ] Пользователь увидел, какие данные будут извлечены.

## AI-onboarding

- [ ] Помощник объяснил, что включать и не включать в архив.
- [ ] Доступна инструкция для устройства пользователя.
- [ ] Исходные файлы не изменяются.
- [ ] Найденные значения имеют источник и уверенность.
- [ ] Ошибки разделены на подтверждённые и предполагаемые.
- [ ] Исправления требуют решения пользователя.
- [ ] Перед импортом показана сводка.
- [ ] Импорт идемпотентен.
- [ ] Отмена и удаление рабочей копии доступны.
- [ ] Ответы базы знаний не смешивают факт, правило и предположение.

## Импорт контрагента

- [ ] Проверен БИН/ИИН.
- [ ] Нормализовано название.
- [ ] Сохранено исходное написание.
- [ ] Проверены адрес и банковские реквизиты.
- [ ] Найдены возможные дубли.
- [ ] Конфликтующие значения требуют подтверждения.

## Создание счёта

- [ ] Компания и контрагент выбраны однозначно.
- [ ] Номер уникален в своей серии.
- [ ] Дата валидна.
- [ ] Товар/услуга классифицированы.
- [ ] Количество × цена = сумма.
- [ ] Итог совпадает с суммой строк.
- [ ] НДС соответствует профилю и операции.
- [ ] Сумма прописью проверена.
- [ ] Печать/подпись применены только в разрешённом режиме.
- [ ] Пользователь подтвердил финальную версию.
- [ ] Для всего счёта допустим один КНП; конфликт требует разделения или подтверждённого правила.
- [ ] Статус «оплачен» не выставляется без платежа или явного подтверждения.

## Проведение продажи

- [ ] Строки унаследованы из подтверждённого счёта либо введены с указанием источника.
- [ ] Товары и услуги разделены.
- [ ] Проверены договор и доверенность.
- [ ] Для товара проверен складской остаток.
- [ ] Складское движение создаётся только при проведении.
- [ ] После проведения тихое редактирование запрещено.
- [ ] Исправление оформляется новой версией или реверсом.
- [ ] Из проведённой продажи создано ЭСФ-обязательство, если применимо.

## Закрывающие документы

- [ ] Для товара подготовлена З-2.
- [ ] Для услуги подготовлена Р-1.
- [ ] Смешанный заказ корректно разделён.
- [ ] Дата фактического события подтверждена.
- [ ] Номер и дата внутри документа совпадают с карточкой и именем файла.
- [ ] Документ связан со счётом, договором и заказом.
- [ ] Зафиксированы отправка, подписание и принятие.
- [ ] В поле основания указан договор или «Без договора», но не номер счёта вместо договора.

## Сопоставление платежа

- [ ] Проверены сумма, дата, плательщик, назначение и банковский счёт.
- [ ] Частичная оплата поддерживается.
- [ ] Переплата не закрывает другой счёт автоматически.
- [ ] Ручное подтверждение сопоставления записывается в аудит.
- [ ] Акт сверки строится из операций и платежей.

## Контроль ЭСФ

- [ ] Зафиксирован налоговый профиль на дату операции.
- [ ] Определена необходимость ЭСФ по детерминированному правилу.
- [ ] Дата оборота подтверждена человеком.
- [ ] Рассчитан срок и его правовое основание.
- [ ] Созданы напоминания.
- [ ] Отправка требует отдельного подтверждения и ЭЦП.
- [ ] Сохранены статус, ID и квитанция.
- [ ] Ошибка отправки не считается успешной операцией.
- [ ] Импортирован внешний регистрационный номер и статус.
- [ ] Отозванная/отменённая/отклонённая ЭСФ не создаёт активную продажу.
- [ ] Статус ожидания подтверждения отзыва создаёт отдельное предупреждение.
- [ ] Исправленная цепочка сохраняет все версии.

## Публичная песочница

- [ ] Только вымышленные реквизиты.
- [ ] Реальные печать и подпись отсутствуют.
- [ ] Нет возможности отправки/подписания.
- [ ] Все документы имеют водяной знак.
- [ ] Данные автоматически очищаются.
- [ ] Пользователь проходит основной сценарий за 3–5 минут.

## Выпуск версии

- [ ] Миграции базы проверены.
- [ ] Автотесты сумм и нумерации пройдены.
- [ ] Проверена изоляция компаний.
- [ ] Резервная копия создана и восстановление проверено.
- [ ] Обновлены ROADMAP и SESSION_NOTES.
- [ ] Изменения налоговых правил имеют источник и дату действия.
- [ ] Нет секретов и реальных данных в Git.
